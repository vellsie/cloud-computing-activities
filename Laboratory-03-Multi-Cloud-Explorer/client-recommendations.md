# Client Recommendations

## Client A – Startup Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

AWS is recommended because it offers many affordable and scalable services that are suitable for startups. The company can start with small resources and increase them as the mobile application grows. AWS also provides flexible pricing options that can help the startup manage its limited budget. Its wide range of services makes it easier to expand the application in the future.

**Services the client could use:**
- Amazon EC2 – Runs application servers.
- Amazon S3 – Stores files and application data.
- AWS Lambda – Runs code without managing servers.
- Amazon RDS – Provides a managed database.

---

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

Microsoft Azure is recommended because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making migration easier. The university can also use Microsoft Entra ID to manage identities and access to cloud services. This allows the university to gradually move selected services to the cloud.

**Services the client could use:**
- Azure Virtual Machines – Runs Windows-based servers in the cloud.
- Microsoft Entra ID – Manages user identities and access.
- Azure SQL Database – Provides a managed database.
- Azure Blob Storage – Stores files and other data.

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

Google Cloud Platform (GCP) is recommended because it provides strong computing, artificial intelligence, and machine learning capabilities. It offers powerful infrastructure that can support demanding AI and ML workloads. GCP also provides specialized AI and machine learning tools that can help researchers develop and train models. Its scalable infrastructure allows the company to increase computing resources when needed.

**Services the client could use:**
- Compute Engine – Provides high-performance virtual machines.
- Google Kubernetes Engine (GKE) – Runs containerized AI applications.
- Vertex AI – Provides tools for developing and deploying machine learning models.
- Cloud Storage – Stores datasets and research files.

---

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

AWS is recommended because it has a large global infrastructure that can support customers around the world. Its services provide high availability and automatic scaling, which are important for a multinational e-commerce company. AWS can automatically increase or decrease resources based on customer demand. This helps the company maintain reliable performance during periods of high traffic.

**Services the client could use:**
- Amazon EC2 – Runs web and application servers.
- Elastic Load Balancing – Distributes traffic across servers.
- Amazon EC2 Auto Scaling – Automatically adjusts computing resources.
- Amazon S3 – Stores product images, files, and other data.
- Amazon CloudFront – Delivers content quickly to users worldwide.
