# Google Cloud Platform (GCP) Research

## Brief Overview
Google Cloud Platform (GCP) is a cloud computing platform provided by Google. It offers computing, storage, databases, networking, artificial intelligence, and data analytics services.

## Global Infrastructure
GCP operates a global infrastructure consisting of Regions and Zones connected through Google's global network. This helps provide reliable and high-performance cloud services.

## Cloud Management Console
The Google Cloud Console is a web-based interface used to create, manage, monitor, and configure Google Cloud resources.

## Four Core Services
1. **Compute Engine** – Provides virtual machines for running applications.
2. **Cloud Storage** – Provides scalable object storage for data and files.
3. **Cloud SQL** – Provides managed relational databases.
4. **Cloud Functions** – Runs event-driven code without managing servers.

## Three Advantages
1. High-performance global network infrastructure.
2. Strong data analytics and artificial intelligence capabilities.
3. Flexible and scalable cloud services.

## Typical Enterprise Use Cases
- Hosting websites and applications.
- Analyzing large amounts of business data.
- Developing artificial intelligence and machine learning solutions.
- Storing and managing enterprise data.
