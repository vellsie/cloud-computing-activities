# AWS Research

## Brief Overview
Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers computing, storage, databases, networking, security, and many other cloud services.

## Global Infrastructure
AWS has a global infrastructure made up of Regions, Availability Zones, and data centers. This allows businesses to deploy applications in different parts of the world and improve reliability.

## Cloud Management Console
The AWS Management Console is a web-based interface used to create, configure, monitor, and manage AWS resources and services.

## Four Core Services
1. **Amazon EC2** – Provides virtual servers for running applications.
2. **Amazon S3** – Provides scalable object storage for files and data.
3. **Amazon RDS** – Provides managed relational databases.
4. **AWS Lambda** – Runs code without requiring users to manage servers.

## Three Advantages
1. Large global infrastructure and wide range of services.
2. Flexible pricing and scalable resources.
3. Strong security and reliability features.

## Typical Enterprise Use Cases
- Hosting websites and business applications.
- Storing and backing up company data.
- Running databases and data analytics.
- Building scalable software and cloud-based systems.
