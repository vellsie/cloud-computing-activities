# Microsoft Azure Research

## Brief Overview
Microsoft Azure is a cloud computing platform developed by Microsoft. It provides services for computing, storage, networking, databases, artificial intelligence, and application development.

## Global Infrastructure
Azure has a worldwide infrastructure consisting of Regions, Availability Zones, and data centers. It allows organizations to deploy applications close to their users.

## Cloud Management Console
The Azure Portal is a web-based management console used to create, configure, monitor, and manage Azure resources and services.

## Four Core Services
1. **Azure Virtual Machines** – Provides virtual computers for running applications.
2. **Azure Blob Storage** – Stores large amounts of unstructured data.
3. **Azure SQL Database** – Provides a managed relational database service.
4. **Azure Functions** – Runs applications and code without managing servers.

## Three Advantages
1. Strong integration with Microsoft products and services.
2. Scalable and flexible cloud resources.
3. Extensive security and enterprise management features.

## Typical Enterprise Use Cases
- Hosting business applications and websites.
- Managing company databases and files.
- Supporting remote and hybrid work environments.
- Developing artificial intelligence and data analytics solutions.
